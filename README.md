# Perimenopause agent (Claude hackathon)

A passive agent for women in the menopause transition: it reads wearable data plus the automated email and calendar she already has, finds her personal patterns, and prepares a visit summary before her doctor's appointment. Everything in this repo runs on **synthetic data** for a fictional persona, Lisa Hartley.

- `lisa_demo_data/` — Lisa's synthetic data, the reference statistics and an inbox preview page. Start with `lisa_demo_data/README.md`.
- Build plan and how each feature works: see the team doc (Build 方案 / 功能怎么实现 tabs).
